# 电子装配厂 · SMT 工单与齐套装配管理

一套面向电子装配厂（SMT 贴片产线）的车间级业务系统：从生产工单下单与排程，
到按 BOM 做齐套备料，再到 SMT 五道工序流转，最后是质检登记与返修闭环。

## 启动

```bash
./start.sh          # 镜像已存在时直接起
./start.sh --build  # 改过代码后必须加 --build
./stop.sh
```

- 前端 http://127.0.0.1:8302
- 后端 http://127.0.0.1:8402
- MySQL 3602 / Redis 6602

## 四个业务模块

### 1. 生产工单
- 工单按机型 + 计划板数下达，带优先级（高/中/低）与交期
- 机型必须已维护 BOM，否则算不出齐套
- 状态：待投产 → 贴片中 → 待检验 → 已完成（不可跳级），可旁路取消

### 2. 齐套备料
- BOM 逐行比对库存：需求 = 单板用量 × 计划板数
- 库存不足或物料非「正常」状态即为缺料
- 齐套率低于 90% 不允许投产；投产时自动铺开 SMT 五道工序并登记初始产线配置

### 3. SMT 工序
- 上料 → 贴片 → 回流焊 → AOI → 目检，固定顺序推进
- 前一道未完成不能开下一道；进行中可退回待执行，已完成是终态（返修场景除外）
- 质检不合格会把对应工序游标置「返修中」（已完成也会回炉停线），该工序不能开工/完工/跳过，
  返修闭环经质检员复验通过后自动恢复为已完成
- 工单存在未放行的换线批次时，贴片工序不能开工也不能完工；已完成的历史工序不受影响

### 4. 质检与返修
- 不良点数超过 12 自动判废，有缺陷但未超判返修，无缺陷判合格
- 判返修必须走完闭环才能放行；判废直接阻塞放行
- 闭环：质检员提交不合格 → 系统以同一质检记录幂等创建/复用返修任务、返修轮次从 1 起、
  对应工序游标置「返修中」→ 返修工完工转「待复验」→ 只能由质检员复验：
  通过才闭环并把工序推进到「已完成」，不通过则返修轮次 +1 退回返修
- 并发口径：质检提交与返修写操作先悲观锁工单行串行化，数据库另有
  `uk_rt_inspection(inspection_id)` 与 `uk_rt_open(order_id, active_step_name)`
  两道唯一索引兜底——重复点击、刷新、网络重试、并发提交都不会产生重复返修任务，
  不同工单不串单；前端提交带 `requestId` 幂等号，同号重放返回同一条记录
- 历史质检（只有 `repair_done`、没有返修任务的旧数据）启动时幂等补建任务并把游标置「返修中」；
  旧接口 `POST /api/inspections/{id}/repair`（空体可调）与旧响应字段保持兼容

### 5. 换线首件放行
- 已投产工单更换设备 / 飞达配置 / 关键工艺参数，必须先建换线批次（配置快照 + 版本号），旧有效批次同时失效
- 批次流转：待首件 → 待确认 → 已放行 / 已驳回；配置再变更或快照过期则已失效
- 操作员提交首件检测结果后只能等质检员确认；提交人与确认人不得同一人
- 驳回必须填原因；操作员可修正后生成新版本（版本号 +1）重新送检
- 确认时配置已被再次修改 → 确认失败且批次标为已失效，不允许用过期快照放行
- 并发口径：所有换线写操作先悲观锁工单行串行化，数据库另有 active_order_id
  唯一索引兜底——重复点击、刷新、并发确认都不会出现两个有效版本

### 后端路线：自定义 Repository fragment

齐套要跨 `work_order` / `bom_item` / `component` 三张表算，派生查询写不出来。
这里单独声明一个 fragment 接口，由实现类手写 JPQL 完成，Spring Data 会把它和
`JpaRepository` 的常规能力合并进同一个 Repository：

- `WorkOrderRepositoryCustom` —— fragment 接口（`findShortageOrders` / `findShortageLines`）
- `WorkOrderRepositoryCustomImpl` —— 手写 JPQL 实现（类名必须是 fragment 接口名 + `Impl`）
- `WorkOrderRepository extends JpaRepository<WorkOrder, Long>, WorkOrderRepositoryCustom`

缺料明细不走 JPQL 构造器投影（参数个数容易对不上），而是查 `Object[]` 后在 Java 里组装
`ShortageLine`。

## 界面

- 主色：靛青 `#283593`
- 导航：左侧纵向时间轴节点导航（下单 → 备料 → 贴片 → 换线 → 质检，节点随当前环节点亮）
- 各页操作范式：
  1. 生产工单——优先级泳道（高/中/低三行，卡片就地展开，换线状态角标）
  2. 齐套备料——BOM 阶梯条（需求条 vs 库存条，缺口标红）+ 齐套率环
  3. SMT 工序——横向工序管道（节点点亮 + 在制游标，换线阻塞横幅）
  4. 换线首件——快照对照（当前配置 vs 上版快照逐字段 diff）+ 版本链 + 处理记录时间线
  5. 质检与返修——缺陷点阵（超阈值整片转红）+ 返修闭环勾选
